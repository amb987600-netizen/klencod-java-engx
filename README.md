# EngX — مساعد الصيانة والورشة (Flutter)

تطبيق صيانة أجهزة طبية يشتغل **بدون إنترنت بالكامل**، عربي RTL مع English، ووضع فاتح/داكن.

## التشغيل (مرة واحدة)

الـ zip فيه كود التطبيق (`lib/`) بس، من غير مجلدات أندرويد/iOS. جوه مجلد المشروع شغّل:

```bash
flutter create . --project-name engx --org com.engx --platforms=android
flutter pub get
flutter run
```

الاختبارات: `flutter test`

بعد `flutter create` ممكن تحتاج تضبط `minSdkVersion` على 21 أو أعلى في `android/app/build.gradle`.

## اللي جاهز

- الأجهزة: بحث وفلاتر، ملف الجهاز (نظرة عامة، سجل، وقائية، قطع، مستندات)، صورة، كود داخلي فريد.
- أمر الصيانة: 4 خطوات، حفظ تلقائي كمسودة، قطع غيار من المخزون، قائمة تحقق قابلة للتعديل،
  الإغلاق على مرحلتين (طلب اعتماد ثم اعتماد Owner/Admin)، والأمر المغلق مقفول (التصحيح بملاحظة).
- المخزون: شريط كمية، تنبيه الحد الأدنى، طلب توفير.
- التقويم: يوم / أسبوع / شهر، التذكيرات والوقائية المستحقة.
- التقارير: أعطال حسب الشهر، جاهزية، زمن إصلاح، تكلفة قطع، تصدير PDF.
- الإعدادات: لغة، وضع، نسخة احتياطية، المزامنة السحابية (مقفولة افتراضيًا).
- قاعدة البيانات: UUID، `workspace_id`، `created_by`، حذف ناعم، `domain`، سجل تعديلات لا يتعدل ولا يتمسح، وطابور مزامنة.
- الأدوار (owner / admin / technician / viewer) متطبقة محليًا في المنطق.

## لسه مش متنفذ (يحتاج حساب سحابي)

- تسجيل الدخول بـ Google، المزامنة الفعلية وحل التعارض، دعوات الفريق، والصلاحيات على السيرفر.
  الجداول (`members`, `invitations`, `sync_queue`, `audit_log`) جاهزة، فالإضافة دي مش هتغيّر هيكل البيانات.
- إشعارات النظام للتذكيرات (التذكيرات بتظهر جوه التطبيق والتقويم).
- المساعد الذكي (مكانه محجوز في التنقل).
- استيراد Excel.

## قواعد السلامة

- التطبيق مبيحطش أي قيمة أو فترة صيانة من عنده؛ كل الأرقام بتدخلها انت.
- ممنوع بيانات مرضى (تحذير تحت خانات النص الحر).
